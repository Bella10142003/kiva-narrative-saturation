# 组员上手指南

> 这个包**不含原始数据和 Python 环境**（太大 + 含借款人隐私信息）。
> 按下面三步，10 分钟就能跑起来。

---

## 第 1 步：装 Python 3.13

检查一下你有没有：

```bash
python3.13 --version
```

没有的话去 [python.org/downloads](https://www.python.org/downloads/) 装 3.13.x。

## 第 2 步：建环境（一条命令）

在解压出来的文件夹里打开终端，运行：

```bash
bash 建立环境.sh
```

脚本会做三件事：建 `.venv` → 装 15 个锁定版本的依赖 → 把它注册成 Jupyter 内核 `Kiva 竞赛 (.venv)`。
大概 2–3 分钟。

<details>
<summary>想手动执行的话</summary>

```bash
python3.13 -m venv .venv
./.venv/bin/pip install -r requirements-lock.txt
./.venv/bin/python -m ipykernel install --user --name kiva-venv --display-name "Kiva 竞赛 (.venv)"
```
</details>

## 第 3 步：放原始数据

从队里拿到 `Kiva_Loans.pkl`（1.49 GB），放到：

```
1_题目与数据/Kiva_Loans.pkl
```

⚠️ **这个文件含借款人姓名、城市、经纬度和故事原文，不要外传、不要上传网盘公开链接、不要提交到 git。**

---

## 开始跑

VS Code 打开这个文件夹 → 进 `3_分析步骤/` → 打开 **[00_安全审计pickle.ipynb](../3_分析步骤/00_安全审计pickle.ipynb)**

右上角 `Select Kernel` → **`Kiva 竞赛 (.venv)`**（找不到就点 `Select Another Kernel...` → `Jupyter Kernel...`）

然后每格点 ▶，按 00 → 17 顺序走。

> 路径是自动定位的，不管你把文件夹放在哪、用户名是什么，都能跑。

## 常见问题

**Q：内核启动失败，说"Python 环境不再可用"**
A：`Cmd+Shift+P` → `Developer: Reload Window`，重载后再选内核。

**Q：`ModuleNotFoundError: No module named 'duckdb'`**
A：选错内核了。别选 anaconda 的 `python3`，要选 `Kiva 竞赛 (.venv)`。

**Q：报错说"找不到项目根目录"**
A：notebook 必须在解压出来的文件夹结构里打开，不能单独把 .ipynb 拷到别处。

**Q：第 00/01 步报错说找不到 Kiva_Loans.pkl**
A：第 3 步没做。从 02 开始跑也行，但需要队里有人把 `4_中间产物/data/raw_parquet/` 的 30 个分片给你。

**Q：跑到一半内存爆了**
A：第 01 步载入 1.5 GB pickle 时峰值约 3 GB。关掉别的程序，或者直接跳过 00–01 用别人给的 parquet。
