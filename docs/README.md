# docs · Working rules

> 团队协作规则与竞赛标准。

How the team worked, kept for the record.

| File | What it is |
|---|---|
| `CONTEST_RULES.md` | The competition standard of record. Everything else defers to this file; where it is silent or ambiguous, the item is marked 【待确认】 rather than filled in by guesswork |
| `AGENTS.md` | Drafting protocol: register every requirement to a source, log evidence before writing prose, never state a plan as an achieved result, self-check before handing off for review |
| `CLAUDE.md` | Review protocol: independent review against the rules, findings graded Blocker / Major / Minor, and a verdict of `APPROVED` or `CHANGES REQUIRED` only — no middle ground, no self-approval |
| `组员须知.md` | Onboarding guide for team members: environment setup in three steps |

The drafting and review roles were kept strictly separate, and neither side could sign off on its own work.
Review outcomes are in [`../7_审查记录/`](../7_审查记录/).
