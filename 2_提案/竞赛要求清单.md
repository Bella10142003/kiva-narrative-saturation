## 8. 冻结的计划主规格

| 方法编号 | 主规格 | 理由/边界 |
| --- | --- | --- |
| MTH-001 | 上线瞬间尚在风险区间且有有效 description 的其他贷款构成共同参照池；已筹满 end=raisedDate，只有确认在主办方支持的 observation end 仍活跃者才于该日删失，已验证的提前退出使用实际终止日；终点未知则降级或停止该分支 | 同时刻代理选择集合；不是实际曝光；不得把所有非筹满记录机械保留到截止日 |
| MTH-002 | 拥挤为 log(1+池规模)；饱和为同池平均 cosine，再 z-score | 两指标同池；饱和除以池规模 |
| MTH-003 | description 的 word unigram/bigram TF–IDF（固定过滤/上限、L2）；cosine similarity | 透明、结果无关、可审计、可扩展，不依赖未确认 AI 规则 |
| MTH-004 | 已筹满时长使用 log1p(days) OLS；预定变换 controls、country/sector/year-month FE；聚类与小聚类备选规则已固定 | 透明、可扩展；仅解释条件关联；year-month 只调整基线时间 |
| MTH-005 | H3 规则在结果前冻结，从完整数据抽 200 条盲于结果双编码；H4 sector 阈值 500 并用 BH 5% FDR，年度用中心化年交互 | 与用户优先级一致，规则不由结果驱动 |
| MTH-006 | 7/14/30 天、其他文本字段/表示、按池规模标准化的阈值占比及原始尺度仅作稳健性；阈值占比固定使用 100,000 个均匀抽取的有效活跃池贷款对（记录固定随机种子）之 cosine 第 95 百分位 | 所有饱和规格仍按池规模标准化；阈值在不看结果时可复现地固定 |
| MTH-007 | 若活跃池无法重建，两指标同步降级为前 14 天队列；有删失时仅把确认在主办方支持的 observation end 仍活跃者删失于该日，已验证的提前退出使用实际终止日，未知风险终点则降级/停止；删失主模型为对 `1 + duration_days`（删失时间同样 +1）的 log-normal AFT，并使用预指定 country/week 双向块 bootstrap；如全已筹满，estimand 仅限 funded loans | 兼容零日记录并处理右删失；不构造删失日，不解释筹满成功 |
