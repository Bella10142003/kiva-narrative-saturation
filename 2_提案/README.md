**[`5 GUYS 提案.pdf`](5%20GUYS%20提案.pdf) is the single source of truth** for what this project promised to
do — *When Every Story Sounds the Same*, structured as RQ1–RQ4. Everything downstream is checked against it.

| File | What it is |
|---|---|
| `5 GUYS 提案.pdf` | The submitted proposal (6 pages). Student IDs redacted for publication |

| `合规对照矩阵.md` | Requirement → scoring criterion → where in the text → supporting evidence |
| `假设清单.md` | Every assumption made, and what remains unconfirmed |
| `证据来源.md` | Evidence log: each verifiable claim traced to a source |
| `_未提交草稿/` | **Superseded.** An earlier *Beyond Crowding* draft (H1–H4) that was never submitted, including one file misleadingly named 定稿 ("final"). Not a valid baseline |

These are working documents and are written in Chinese; the proposal itself and all deliverables are English.
