# 在模拟数据上试跑 v4 提案：每个环节到底有没有用

**结论先行。** 整条流程在 20,000 条模拟数据上跑完只要 **38 秒**，计算不是瓶颈。真正的问题在别处：v4 里的 14 个方法论环节，实测下来 **3 个是真有用的、4 个恒为空转、5 个在写法上会误导、2 个反而让估计变差**。砍掉空转与误导的部分，分析工作量减少约一半，而能站得住的结论一个不少。

---

## 一、这份模拟数据是什么

20,000 条贷款，2016-01-01 至 2025-12-31，字段与官方 100 条样本完全同构（27 个字段，同名同类型）。校准到真实样本的分布：筹资时长中位数 62.3 小时（真实样本 61.7），最长 839.9 小时（真实 840.0），贷款金额中位数 350（真实 362.5）。8.9% 未募满，其中 3.0% 连终止日期都无法核实。

数据里**故意埋了六件事**，每一件都对应提案里的一句话，让那句话变成可证伪的：

| 埋进去的东西 | 对应提案里的哪句话 |
|---|---|
| 已知的真实系数 β₁…β₆（标准化后 β₃=0.117、β₆=0.037） | 2×3 测量矩阵能不能把两条通道分开 |
| 行业-周冲击 u[s,w]（分析端不可观测，week FE 吸收不了） | 「主动池被结果污染，所以要镜像池」 |
| 72 家合作机构，模板强度与募资速度同时受机构规模驱动 | 「没有 partner identifier 是无法根治的残留混杂」 |
| 模板化比例逐年 0.25→0.70，池规模 3.6→12.5，同质度 0.105→0.211 | RQ3 的两条方向性预测 |
| 8.9% 未募满 + 3.0% 终止日期不可核实 | 删失模型与「镜像池转为主」的兜底分支 |
| 真实驱动来自 **use** 字段而非 description | 「难以区分发生在扫描阶段」 |

主动池由此前贷款的**实现端点**决定，按时间顺序逐条模拟——所以内生性是长出来的，不是事后加的噪音。实测 `corr(冲击, 主动池规模) = +0.132`，而 `corr(冲击, 镜像池规模) = +0.016`。

> **一个必须记住的尺度差**：20,000 条摊到 10 年、11 个行业上，行业主动池平均只有 9 条；真实的 145 万条上这个池子约大 70 倍。所以下面凡是涉及**精度**的结论都偏保守——在这里能测出来的，在真实数据上只会更好；在这里测不出来的，才需要看功效外推。

## 二、三个真有用的环节

### 1. 双池镜像 —— 全设计里性价比最高的一环

主动池（上架时仍在架的同行业贷款）的拥挤度系数被严重高估：

| 规格 | C 的估计 | 真值 |
|---|---|---|
| 主动池 | **0.444** | 0.138 |
| 主动池 + 控制住真实冲击（作弊对照） | 0.089 | 0.138 |
| **镜像池（前 14 天发布，不论后续状态）** | **0.107** | 0.138 |

主动池把 C 高估了 3.2 倍。作弊对照证明偏误确实来自那个不可观测的行业-周冲击。而镜像池在**完全不知道冲击存在**的情况下，把估计拉回到几乎无偏。

**判定：保留，并升为主规格**（提案现在是「主动池为主、镜像池为辅」，应当对调）。代价是同质度会被衰减——H 从真值 0.170 掉到 0.054，C×H 从 0.117 掉到 0.042——因为镜像池是真实主动池的一个带噪声代理，经典的衰减偏误。这是一笔明确的交易：**用系数衰减换掉内生性偏误**。提案应当直说这一点，而不是含糊地说「只解释方向与幅度都一致的结果」。

### 2. use 与 description 的对照 —— 有用，但只需要一次

| 测量 | 与真值的相关 |
|---|---|
| 主动池同质度 H（use 字段） | **0.999** |
| 主动池同质度 H（description 字段） | 0.538 |

在本模拟设定下真实驱动来自 use，所以这个数字本身是「假设的回声」，不是发现。但它验证了一件有价值的事：**两个字段测出来的东西差别极大**（相关只有 0.54），所以「在哪个字段上测」是一个会改变结论的决定，值得在提案里交代。

**判定：简化。** use 为主测量，description 只做一次一致性对照，不必两条并行跑完整套模型。

### 3. Day 1 审计 —— 但只有四项真的改变了后续动作

跑下来，审计里真正**触发了决定**的只有：

- `whySpecial` 只有 38 个不同取值 / 20,000 行（0.19%）→ 按提案自己的规则应当剔除 ✅ 规则生效了
- 已募满贷款的最长时长 839.9 小时 → **L 冻结在 35 天**
- 3.0% 的贷款终止日期无法核实 → 触发兜底假设
- 池规模分布（均值 9.0，39% 达到 10 条）→ 直接决定门槛怎么设

其余审计项（重复 ID、语言、缺失率、重复文本 0.045%）全部通过，没有改变任何一个决定。

**判定：保留但收缩到这四项。**

## 三、四个恒为空转的环节

### 4. 「报告滞后池中仍在架的占比，并排除后重估」

实测 **0.0%**。因为 L 被冻结在募资期限上限（35 天），而任何贷款最晚 35 天就离开页面——**只要 L 取上限，重叠在构造上必然为零**。这项检验在真实数据上同样恒为零，写进去是纯粹的字数消耗。

**判定：删除。** 换成一句话说明「L 取募资上限，因此滞后池与主动池在构造上不重叠」，同时也解决了交接简报里第五节第 2 项那个开放问题。

### 5. 平台级池的重构

平台级池的拥挤度系数是 **−0.49**（真值 +0.138），符号都反了。原因很直接：平台级上架量在一周之内几乎是常数，week 固定效应把它的变异吃干净了，剩下的是噪音。

**判定：删除。** RQ4 里「注意力市场在行业级还是平台级」这个问句可以保留为讨论，但不能靠这个回归回答。

### 6. 受限三次样条

真值是线性的，样条**理应**什么也测不到——实测确实如此（两项 t = +0.90 和 −1.58，其中一项数值退化，标准误算成 0）。问题是：它在真值非线性时能不能测到，本次模拟没有回答；而它在真值线性时会引入数值不稳定，这倒是测到了。

**判定：删除。** 换成对 H 的分位数分箱图（Day 6-7 的演示工具里本来就要画），零成本，且比样条更容易讲。

### 7. 3 天 / 14 天半衰期敏感性

7 天半衰期下第 44 天的权重只有第 15 天的 5.7%——真正做工的是半衰期而不是硬截断。敏感性检验换成 3 天或 14 天，滞后池测量的秩相关变化极小，估计不动。

**判定：从提案正文删除**（放进附录一句话）。省下的字数拿去写清楚 L 的定义。

## 四、五个写法会误导的环节

### 8. 池规模 ≥10 的门槛 —— 反而把 β₃ 打没了

| 门槛 | N | C×H 估计 | 真值 |
|---|---|---|---|
| 不设门槛 | 16,818 | **0.077** (t=4.3) | 0.117 |
| ≥5 | 11,132 | −0.035 (t=−0.8) | 0.117 |
| ≥10 | 7,018 | **−0.002** (t=0.0) | 0.117 |

原因不难理解：**C 的变异正是识别 C×H 的来源**，而池规模门槛恰好把 C 小的那一半样本切掉了，交互项就没有杠杆了。提案里「N=2 的池子算出的均值是纯噪音」这个理由本身没错，但它保护的是 H 的测量质量，代价是 C 的识别力，而后者更贵。

**判定：改写。** 主规格不设门槛（只要求池非空），报告池规模分布，把 ≥10 降为稳健性检验。注意：真实数据上池子大 70 倍，门槛几乎不会剔除任何行——**所以这一条严格说是本次小样本的产物**，但它揭示的机制（门槛与识别力的取舍）在真实数据上依然成立，值得在提案里改成「报告分布，不设硬门槛」。

### 9. 安慰剂的「1/3 判据」—— 在噪音上不可评估

前向窗口 V×G = 0.0406，后向 V×G = 0.0411，**比值 0.99**，远超提案要求的 1/3。按提案的判据，这个设计**没通过安慰剂检验**。

但真实的前向效应是 **0**。两个系数都不显著（t = 0.58 与 0.80）——它们都是噪音，而两个噪音的比值当然什么也说明不了。**「前向系数须低于后向系数的 1/3」这条判据在后向系数本身不显著时是无意义的，而且会让一个完全正确的设计不及格。**

**判定：改判据。** 换成两条：(a) 前向系数的置信区间须覆盖 0；(b) 前向与后向相等的检验须拒绝——**且仅在后向系数本身显著时才执行这个检验**。这是一处真实的逻辑漏洞，不改会在答辩时被问住。

### 10. Raw / Residual 模板分解 —— 几乎不动结果

| 规格 | H | C×H |
|---|---|---|
| description 原文 | 0.043 | 0.053 |
| description 去模板残差 | 0.050 | 0.023 |
| **加入真实的 partner 固定效应（作弊对照）** | 0.102 → 0.102 | 0.077 → **0.078** |

去掉模板后估计基本不动。更关键的是那个作弊对照：把**真实的机构固定效应**放进去，C×H 从 0.077 变成 0.078——**机构混杂在本设定下根本不构成实质偏误**。也就是说，提案里用一整段篇幅辩护的「raw/residual 分解替代 partner FE」，解决的是一个（至少在这个数据生成过程下）不存在的问题。

**判定：大幅降级。** 保留 `boilerplate_share` 作为一个协变量（一行代码），把整段分解降为一句稳健性说明。省下约 60 词。

⚠️ 这是本次模拟中最需要打折看待的一条：结论依赖于我设定的机构效应大小。真实 Kiva 上不同 Lending Partner 的募资速度差异可能远大于此。**稳妥的说法是：不要把「模板分解」当成识别策略来辩护，把它当成一个描述性稳健性检验。**

### 11. RQ4 分行业 —— 只有前三个行业跑得动

| 行业 | N | C×H (se) |
|---|---|---|
| Agriculture | 4,174 | −0.042 (0.162) |
| Food | 1,735 | −0.066 (0.143) |
| Retail | 1,055 | 0.170 (0.407) |
| Services | 20 | −0.197 (数值退化) |
| Housing | 6 | 0.259 (数值退化) |
| Education | 18 | −0.232 (数值退化) |

真值里**各行业系数完全相同**（不存在真实异质性），但估计从 −0.23 摆到 +0.26。如果按点估计讲故事，会讲出一个纯属虚构的行业差异。这正是提案里等价性规则要防的事——而这个规则确实该留。

**判定：缩到前三大行业 + 一次联合交互检验 + 等价性区间。** 后面几个行业连固定效应都吸收不掉，FDR 校正无从谈起。

### 12. 删失（AFT）模型 —— 比直接用已募满样本更差

| 参数 | 真值 | OLS（仅已募满） | AFT（右删失） |
|---|---|---|---|
| C | 0.138 | 0.444 | **0.695** |
| C×H | 0.117 | −0.002 | 0.083 |
| V×G | 0.037 | 0.041 | **−0.089** |

AFT 在 C 上偏得更远，在 V×G 上直接变号。删失只影响 8.9% 的样本，而模型设定风险影响全部。

**判定：降级为附录。** 主分析用已募满样本，正文报告未募满比例及其与各测量的相关性（这是更诚实也更便宜的处理）。

## 五、RQ3：功效最紧的一环，必须改写法

这是最重要的一条。RQ3 在提案里被写成两条**方向性预测**（主动饱和逐年增强、近期饱和相对增强更快），并用「饱和项 × 年份」的交互系数来检验。实测：

| | 真值 | 20k 上的估计 | 145 万上的功效外推 |
|---|---|---|---|
| C×H × 年份 | +0.0064/年 | +0.0020 (se 0.0051) | se≈0.0027，**t≈2.4** |
| V×G × 年份 | +0.0048/年 | **−0.0039** (符号反了) | se≈0.0026，**t≈1.9** |

分样本写法也没有救回来：2016-20 与 2021-25 的 V×G 是 0.058 → 0.018，**方向与真值相反**。

功效外推做了组内相关校正（每周行数从 34 升到 2,812，ρ≈0.010，设计效应从 1.16× 升到约 5.5×）——朴素的 √N 外推会把功效高估三倍以上。校正后：

- **β₃ (C×H)：t≈13.7** → 在真实数据上稳稳能测
- **β₆ (V×G)：t≈4.6** → 能测
- **两个年度交互：t≈2.4 与 1.9** → 在临界线上

**判定：RQ3 保留（brief 强制要求演化视角），但把定量断言降级。** 具体：把「两条方向性预测」改写成「逐年边际效应及其置信区间的描述性刻画」，明确标注为探索性。理由要写在提案里：年度交互是把主效应再切十份，功效天然是主检验的 1/5。

这么改还有一个附带好处——交接简报里担心的「β₆ 在构造上偏保守，零结果不是磨损不存在的证据」这句话，正好可以并到这里，一次说清楚。

## 六、可行性：计算不是问题

| 步骤 | 20,000 条耗时 |
|---|---|
| Day 1 审计 | 0.2 秒 |
| 文本清洗 + 掩码 | 0.4 秒 |
| TF-IDF 向量化（use + description） | 1.7 秒 |
| 模板句识别 | 0.6 秒 |
| 主动池（滚动稀疏和） | 3.2 秒 |
| 滞后池（衰减加权） | 4.6 秒 |
| 镜像池 | 4.7 秒 |
| 前向安慰剂池 | 4.6 秒 |
| 全部 11 个回归（双向聚类 SE） | 2.2 秒 |
| **全流程** | **38 秒** |

外推到 145 万条：池构建是每条贷款 O(词表大小) 的稠密向量加减，词表会从 1,376（use）涨到大约 3-5 万，所以**主导项是 词表 × 行数**。粗估单次池构建 25-40 分钟，全流程一次跑通约 2-3 小时。**一周之内完全跑得完，前提是不要跑四遍池**——这正是砍掉平台级池和多余稳健性检验的第二个理由。

真正的瓶颈不是 CPU，是内存：145 万条 description 的 TF-IDF 稀疏矩阵约 3-6 GB，加上每个行业一份稠密池向量。建议在 use 字段上跑全部主分析（词表小一个量级），description 只跑一次对照。

## 八、这份模拟不能回答什么

诚实地划一下边界：

1. **凡是「真值是我设的」的地方，结论就是假设的回声。** 「use 比 description 更贴近真值」「机构混杂不构成偏误」「效应量是这么大」——这三条都是我在生成端设定的，不是发现。它们的价值在于：**在这些设定下，这套估计程序能不能还原出来**。
2. **池规模只有真实数据的 1/70。** 所有关于门槛、关于小分组精度的结论都偏保守。
3. **没有检验非线性。** 真值是线性的，所以「样条测不到东西」不等于「真实数据上样条没用」。它只说明样条在这个流程里数值不稳。
4. **文本生成是模板拼接，不是真实借款人叙事。** 余弦相似度的绝对水平不可外推；只有「哪个测量还原了哪个真值」这类相对结论可外推。
5. **功效外推依赖我设定的效应量。** 若真实效应更小，145 万条也可能不够——但至少现在有了一个可以调参数重跑的框架（`generate_kiva_sim.py` 里改 `TRUE` 字典即可）。
